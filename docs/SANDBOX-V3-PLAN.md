## 1. 当前核心痛点诊断（基于用户实测 + 代码实查）

1. **间距过窄且默认开局自动连环撞击**：
   - `data.js` 原版轨道（`14 / 23 / 33 / 46 / 60 / 75`）与半径（`2.05 ~ 4.4`）是为静观展示艺术压缩的，相邻轨道净缝隙仅 `3.5 ~ 6` 单位。
   - 沙盒开局把 `12.4 M☉` 的归墟直接放在 `r = 67` 并赋予 `0.62×` 欠速椭圆轨，导致不操作几秒内就拽偏六星连环相撞。
   - 默认时间推进偏快且 `update()` 把单帧 `dtSim` 硬截断在 `0.12`，倍率范围只有 `0.15× ~ 2.5×`。
2. **行星间引力过弱、无法贴脸捕获卫星**：
   - `dominantAttractorNear()` 过滤掉了所有行星（只认恒星/黑洞/脉冲星），贴着巨行星放小天体时仍按远处恒星配速，瞬间飞散。
   - 紧凑轨道导致行星希尔球被主星严重压缩，且缺少独立的行星间互引倍率参数。
3. **碰撞反馈流于“闪一下”，缺少持久演化后果**：
   - 目前只有直接隐藏合并或全碎，没有斜向擦边质量剥离（Hit-and-Run）、质量损耗、合并生成**持久旋转立体碎屑星环**、以及大撞击凝结**新生小卫星**。
4. **可调参数偏少，缺少天体深度物理属性与临界保护**：
   - 缺少公转速度精确调节、自转速度/离心扁平变形/临界自转解体、表面逃逸速度、表面重力、密度、温度演化、自转轴倾角、轨道偏心率/希尔球，以及「超临界不解体」锁定开关与「空间锚点钉死」开关。
5. **空间缺乏参照物、易晕且易丢目标**：
   - 沙盒隐藏了原版星图，缺少 AU 极坐标距离刻度环、实时沙盒雷达与天体定位列表、以及离屏天体边缘指向标。
6. **造物难静止放置、发射速度不直观、缺阵型快照**：
   - 单击强行套圆轨速度，无法一键静止放置（`0 km/s`）；拉弓时鼠标旁缺少实时速率/圆轨比/逃逸比标尺；调好阵型后没有快照存档/回滚。

## 2. 宇宙沙盒 3.0 完整方案（含主动补齐的天文物理体系）

### A. 全局宇宙法则与时间引擎（精简底栏 + 可折叠「物理法则」抽屉）
- **真·宽范围时间倍率（`0.05×` ～ `100×`）**：
  - 快捷档位：`Ⅱ` / `0.1×` / `0.5×` / `1×` / `5×` / `20×` / `100×` + 对数平滑滑块（最低可到 `0.05×`）。
  - **高倍速稳定积分器**：放开 `dtSim` 截断，按有效 `dtSim` 动态扩展 Verlet 子步数（`6 ~ 48` 步）并加**线段扫掠防穿模碰撞检测（CCD）**，确保 `100×` 下既真快 100 倍又不穿模漏撞、不能量爆炸。
- **稳态宽间距默认开局 + 轨道间距倍率**：
  - 默认沙盒启动时自动应用宽间距稳定构型（行星轨道按约 `2.1×` 舒展、归墟置于外围稳定伴轨），**不主动干预可稳定运行不自撞**；并暴露「轨道间距 `0.6× ~ 3.0×`」参数。
- **全局物理法则参数抽屉**：
  - 万有引力倍率（`-2.0×` 反重力 ～ `0.0×` 失重 ～ `+5.0×` 超重）
  - **行星间互引倍率**（`1× ~ 25×`，默认适度增强如 `4×`，轻松玩双行星互绕与卫星捕获）
  - **碰撞模式 / 碎裂阈值**（正常写实 / 温和吸积 / 纯弹性台球）
  - **星际介质阻力（轨道阻尼）**（`0% ~ 100%`，打开后轨道能量缓慢耗散，呈现真实螺旋吸积坠落）
  - **全局临界解体开关**（`开启 / 关闭不解体`：关闭后自转超限、越过洛希极限或超高速撞击均不撕碎解体，专供极限物理奇观测试）
- **阵型快照（保存 / 回滚）**：
  - 一键保存当前全部天体的位置、速度、质量、半径、自转、温度、环系等完整状态；随时一键回到快照，反复测试不同初速度/参数而无需重置整盘。

### B. 全维度天体属性仪表盘（左侧升级版 `#sb-inspector`）
选中任意天体后展示并支持实时调控（按分组折叠/紧凑排布，不挡主视野）：
1. **结构与引力参数**：
   - **质量（Mass）**（按尺度自适应显示 $M_\oplus$ / $M_J$ / $M_\odot$）
   - **半径（Radius）** 与派生 **平均密度（$\text{g/cm}^3$）**（调半径实时影响表面重力、逃逸速度与洛希极限）
   - **表面重力（$g = GM/R^2$）** 与 **逃逸速度（$v_{\text{esc}} = \sqrt{2GM/R}$）**
   - **希尔球半径（Hill Sphere）** 与 **洛希安全余量（%）**
2. **公转与轨道动力学**：
   - 实时速率（`km/s`）、**轨道偏心率 $e$**、轨道状态标签（`静止` / `近圆` / `椭圆` / `双曲线逃逸`）
   - **公转速度滑块** + 快捷按钮：**`设为静止 (0)`**、**`精准圆轨 (100%)`**、**`反向逆行`**
3. **自转、离心变形与临界解体**：
   - **自转角速度 / 自转周期（h）** 滑块 + **自转轴倾角（`0° ~ 90°`）**
   - 实时计算并标出 **临界瓦解转速（$v_{\text{breakup}} = \sqrt{GM/R}$）**
   - 视觉联动：高速自转触发**离心赤道扁平变形（扁球体）**；超过临界值且允许解体时，从赤道甩出炽热碎屑流并**离心解体成碎片环带**；关闭解体或开启单星锁定后维持超极限扁平狂转不炸。
4. **热力学与形态转化链（Emergent States）**：
   - **表面温度（K）**（随恒星反平方辐照 + 撞击熔岩余热 + 潮汐摩擦动态变化，也支持手动加热/冷却）
   - 温度外观反馈：极寒霜壳 → 温带 → 云海蒸发 → 炽红熔岩海 → 超近星高温蒸发尾流（缓慢失重）
   - **状态转化链**：
     - 气态巨星遭强潮汐/高温剥离 → 裸露高密度岩核（**冥府行星 Chthonian**）
     - 超重行星 → 褐矮星 → 点火成红矮/主序恒星
     - 超重恒星 / 碰撞超限 / 白矮星吸积破钱德拉塞卡极限 → **超新星爆发** → 中子星或新生黑洞
     - 中子星双撞或超重 → **千新星** → 新生黑洞
5. **单星专属保护锁**：
   - **`🔒 不解体锁`**（该天体免疫自转解体、洛希撕裂与撞击粉碎）
   - **`📌 空间锚点`**（将该天体钉死在空间坐标中不动，专作引力靶桩或弹弓支点）

### C. 深度碰撞演化与持久星环系统
将行星/天体碰撞从“闪一下隐藏”升级为 **4 档持久反馈**：
1. **温和吸积合并（Accretionary Merger）**：
   - 质量与体积守恒合并成**明显更大的熔岩巨星**；撞击偏心角动量**真实改变并加速幸存天体自转**（若冲破临界自转会引发二次离心甩料！）。
   - 根据撞击能量与角动量，在幸存星赤道生成一圈**持久旋转的立体碎屑星环（动态 Shader 环网格，支持叠加/冷却）**。
2. **斜向擦边质量剥离（Hit-and-Run / Grazing）**：
   - 偏心擦撞且相对速度适中时，两星均存活但发生**真实质量损耗（10%～35%）与半径收缩**、表面撕裂升温；剥离出的地幔碎屑一部分成环，一部分在条件满足时**凝聚成 1～2 颗环绕幸存星的新生小卫星**（地月大碰撞模型）。
3. **超高速粉碎（Catastrophic Shatter）**：
   - 双星解体为围绕主引力源长期旋绕的炽热碎片云带 + 多层冲击波。
4. **超临界坍缩转化**：
   - 大质量对撞或白矮星/恒星/中子星碰撞按物理极限直接引发超新星/千新星/引力波并合与残骸新生。

### D. 造物发射升级与天体模板扩充
- **3 种投放速度模式（造物栏直接切换）**：
  - **`静止 (0)`**：点哪就绝对静止生成。
  - **`自动入轨`**：`dominantAttractorNear()` 改为按真实场强 $GM/d^2$ 涵盖**所有天体（含气态巨星与岩质行星）**，贴着大行星单击直接自动配成卫星圆轨（可选顺行/逆行）。
  - **`拉弓 / 定速发射`**：支持手动预设发射速度；拉弓拖拽时鼠标旁实时贴身浮动 **速度标尺浮标**（显示 `速率 km/s`、`圆轨比 ×v_circ`、`逃逸比 ×v_esc` 与轨道判定 `坠落 / 椭圆 / 逃逸 / 引力弹弓`）。
- **扩充造物模板**（原有 8 类基础上补充）：
  - **冰质小卫星**（低质量，专为行星配月/测希尔球捕获）
  - **白矮星**（超高密度致密星，吸积或相撞可触发 Ia 型超新星）
  - **褐矮星**（介于气态巨星与红矮星之间的次恒星）
  - **碎屑星环注入**（一键给选中天体铺一圈测试碎屑带）

### E. 三维空间参照系（彻底防晕）+ 物理日志
1. **极坐标星盘刻度标尺**：时空网格叠加清晰的同心 AU 距离环与 `0° / 90° / 180° / 270°` 方位十字轴线（支持随缩放自适应透明度）。
2. **右上角实时沙盒星图雷达 & 存活天体列表**：可折叠面板，实时标示所有恒星、黑洞、行星、卫星与探测器位置，**单击任意条目直接平滑居中聚焦，双击锁定追踪**。
3. **屏幕边缘离屏指向标**：恒星、黑洞、选中或追踪天体移出视野时，在屏幕边缘显示带颜色与距离的微型方向箭头。
4. **可展开物理事件日志**：记录碰撞质量损耗、产环、产卫星、自转解体、形态转化、引力弹弓 Δv 与彩蛋解锁，不再因横幅覆盖而错过因果。
